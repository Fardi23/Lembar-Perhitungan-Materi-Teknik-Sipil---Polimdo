# Lembar-Perhitungan-Materi-Teknik-Sipil---Polimdo
Lembar Perhitungan Materi Teknik Sipil – Polimdo merupakan platform digital untuk mendukung pembelajaran, analisis, dan perencanaan teknik sipil melalui kalkulator interaktif, lembar kerja perhitungan, visualisasi, serta referensi standar SNI bagi mahasiswa, dosen, dan praktisi.
